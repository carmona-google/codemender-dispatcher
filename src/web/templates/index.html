Interactive Lifecycle & GitHub PR Delivery

  • 0. IMPORT cm import: Ingest local .json reports from external tools (Wiz Code, SARIF, Snyk, Trivy, Semgrep) and correlate them with your codebase.
  • 1. SCAN cm find: Parses AST, CI/CD workflows, and dependency manifests to identify candidate vulnerabilities.
  • 2. VERIFY cm verify: Select specific Finding IDs to detonate PoC harnesses inside an air-gapped (--network=none) gVisor sandbox.
  • 3. FIX cm fix: Select verified Finding IDs to generate and regression-test unified .diff patches.
  • 4. PR GitHub PR: Pushes a clean remediation branch and opens a Pull Request via carmona-google with the Fix changes.
